# 対局サポートアプリについて
対局中の以下の点についてアプリでサポートまたは代用できないか？
- 現在の自動卓では親の連荘数が分かりにくい。<br>百点棒を置く方式だと親が流れた場合の回収忘れなどが発生する可能性がある。
- 全員の点数状況がわからない。
- 千点棒がない場合に両替しないとリーチできない。
- 流局時の本場継続なのかどうかが不明瞭になっていて、日によって変わってしまうことがある。

### サポートアプリの案
- 卓の中央にiPadを置く
- 各自の点数表示機能
- （表示領域に余裕があれば、他3者との点差表示機能も）
- リーチ管理機能
  - ボタン一つでリーチできる。
  - リーチしたら-1000点する
  - 供託に+1する
  - リーチ表示
- 点数自動計算機能
  - 音声入力で「誰がどうあがったか」「何点なのか」を入力すると、本場と供託の状況を含めた点数移動結果を画面表示する機能。
