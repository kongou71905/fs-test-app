# 要件定義
「何を作るか」を決める工程です。

## 決める内容
- 利用者は誰か
  - アプリ作者自身

- 何を実現したいか
	- 麻雀の成績を管理する。
 	- 1試合の結果について、各自の[席順、持ち点、焼き鳥、飛ばし者、残留供託棒]を入力することで集計を自動化する。
	- 1日の試合結果と総合成績を自動計算し、一覧表示する。
	- 過去の成績について、年ごと、または、通算の一覧を表示する。
 	- 各種成績はwebサーバ側にファイルとして保存し、アプリ経由でダウンロードも可能とする。

- 必要な機能
	- 対局者を管理する機能
 	- 1試合の結果を入力する機能
	- 1日の試合結果と総合成績を一覧表示する機能。
	- 過去の成績を一覧表示する機能。
	- 各種成績のファイル保存機能。
  	- 成績ファイルのダウンロード機能。

- セキュリティ要件	
	- なし。（自分のみが利用する。URLを自分以外に教えない。という前提のため）

- 性能要件	
	- なし。（自分のみが利用するため）

- 利用する環境	
	- GitHub Pages

- 成果物		
	- 要件定義書		
		- このシート内容とする。
