# 利用シーンの整理

- アプリ開始
1. モード選択画面
    - 対局者管理画面へ遷移
    - 過去データ画面へ遷移
    - 成績表示画面へ遷移
1. 対局者管理画面
    - 対局者マスタを管理する画面。
    - 対局者IDと対局者名を紐づけて管理する。
    - レコードの追加と削除を可能とする。
    - 対局者名の変更も可能とする。
    - 対局者IDと対局者名はユニークとする。
    - レコードの総数は10件までとする。
    - マスタの内容はweb側ファイルに保存すること。
1. 過去データ画面
    - web側の成績ファイルを読み込み、内容を一覧表示する機能。
    - 既存の簡易版一覧画面で表示すること。
    - 各日付をタップすることで、その日の成績表示画面を表示すること。
1. 成績表示画面
    - 日付対局者設定画面を表示する。
        - 日付を入力する
        - 対局者を4人以上入力する。
        - 確定で成績表示画面へ遷移
    - 入力ボタンを押す。
    - 成績入力画面が表示される。
        - 4人分の対局者、点数、焼き鳥、飛ばしを設定する。
        - 供託数を入力する。
        - OKボタンを押下する。
        - 点数の整合性チェックを実施する。
            - NGだった場合は、警告メッセージを表示し、成績入力画面に戻る。
        - 成績表示画面へ遷移する。
        - 対局結果欄の最老番に成績を追加する。
        - ここまでの入力を任意の局数分実施する。
- （集計段階）
    - チップボタンを押す。
    - チップ入力画面が表示される。
        - 各対局者のチップ所持数を入力する。（所持枚数をそのまま入力する）
        - OKボタンを押下する。
        - 整合性チェックを実施する。
            - NGだった場合は、警告メッセージを表示し、チップ入力画面に戻る。
        - 成績表示画面へ遷移する。
        - 対局結果欄の最老番にチップ成績を追加する。
- （終了段階）
    - 終了ボタンを押す。
    - 成績ファイルに今回の成績を書き込む
    - モード選択画面に遷移する
