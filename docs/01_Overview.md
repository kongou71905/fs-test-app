# 大まかな要望
- 麻雀の成績管理について、これまでは紙への手入力＆手計算で行っているが、これをアプリで代用したい。
- 使用可能な端末は現実的にiPad mini6しかないため、iPad mini6で使用可能なアプリとしたい。

# 要件定義
- 半荘ごとに対局者4人の成績を簡単に入力できること。
- 入力された成績から、その半荘の結果を1画面で表示できること。
- 成績入力と半荘結果表示は、任意の回数繰り返し実行できること。
- 入力された成績はいつでも・簡単に修正できること。
- 1日の全ての半荘結果一覧と、1日の最終成績を1画面で表示できること。
（参加人数が多い場合や、半荘数が多い場合はスクロール表示でも良い）
- 入力された半荘ごとの成績と1日の最終成績はファイルに保存すること。
- 過去の「半荘ごとの成績」と「1日の最終成績」はまとめて一覧表示できること。
- 利用形態として以下の想定とする。
	- 自分のiPadで利用する。
	- 自分と限られた数人のみで利用する。
	- オンライン環境で利用する。
	- 成績結果の共有はスクショをLINEで共有する想定。
	- 別途分析のため成績は扱いやすいファイル形式で保存できること。

# アプリ形態
- 当初はiPadで動作する自作アプリを想定していたが、iOSアプリ開発にはMac端末が必要orクラウドビルドサービス利用が必須、	
かつ、端末へインストールするにはAppleデベロッパー有料契約が必要ということがわかったのでiOSアプリは断念する。	
- 代替案として、Webアプリ形式で作成しiPadからsafariで接続して使用する形態とする。
